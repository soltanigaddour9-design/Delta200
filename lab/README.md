# Diploma Lab

A study app for Cambridge Delta (Modules 1, 2 and 3) and the Trinity DipTESOL, built for Kader.

90 topics in 12 colour-coded areas, 213 scholars with 234 key works, 282 glossary terms, 188 quiz questions and 12 games.
Each topic runs Predict, Understand, Who says so (scholars and sources), Classroom, Exam angle, Watch out, Close and recall, Check yourself.
Progress, spaced review (day 2, 5, 12, 30) and flashcard boxes are saved in the browser.

IELTS Academic section: Writing Task 1 (7 visual types with charts and models), Task 2 (6 question types and a timed 6-minute planner),
Speaking (4 frames with a visual timer), 87 C2 phrases tagged for speaking or writing, and 11 purpose-built practice games.

No build step: plain HTML, CSS and JavaScript modules. Served by GitHub Pages from the main branch.
